# 🚀 C++ Move Semantics Demo

Цей проєкт створено для демонстрації та пояснення концепції **Move Semantics (семантики переміщення)** та функції `std::move` у сучасному C++ (C++11+).

## 💡 У чому проблема?
У класичному C++ при передачі або поверненні великих об'єктів (наприклад, динамічних масивів чи векторів) часто відбувалося *глибоке копіювання (deep copy)*. Програма виділяла нову пам'ять у купі (heap), копіювала туди всі байти, а старий тимчасовий об'єкт одразу знищувався. Це створювало великі накладні витрати на продуктивність.

## 🛠️ Як це вирішує Move Semantics?
Замість того щоб копіювати дані, *семантика переміщення* дозволяє «забрати» внутрішній вказівник у тимчасового об'єкта (rvalue) і передати його новому власнику. 
* **Копіювання:** дублює дані (довго і дорого).
* **Переміщення:** просто перенаправляє вказівник (миттєво, за $O(1)$).

## 💻 Демонстраційний код

Ось як реалізуються Конструктор переміщення та Оператор присвоєння з переміщенням:

```cpp
// Конструктор переміщення (Move Constructor)
DynamicBuffer(DynamicBuffer&& other) noexcept 
    : data(other.data), size(other.size) {
    other.data = nullptr;
    other.size = 0;
}

// Оператор присвоєння з переміщенням (Move Assignment Operator)
DynamicBuffer& operator=(DynamicBuffer&& other) noexcept {
    if (this != &other) {
        delete[] data;          // Видаляємо власні старі дані
        data = other.data;      // Забираємо дані іншого об'єкта
        size = other.size;
        other.data = nullptr;   // Обнуляємо інший об'єкт
        other.size = 0;
    }
    return *this;
}
